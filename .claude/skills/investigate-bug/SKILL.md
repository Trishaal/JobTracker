# Investigate Bug

## Process

1. Understand the reported behaviour.
2. Identify the expected behaviour.
3. Reproduce the issue where practical.
4. Inspect logs, tests, and relevant code.
5. Identify the root cause before making changes.
6. Implement the smallest appropriate fix.
7. Add or update regression tests.
8. Run relevant validation.

Do not make speculative changes across multiple areas without evidence.

Prefer understanding the root cause over trial-and-error changes.

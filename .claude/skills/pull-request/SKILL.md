# Pull Request Workflow

Before creating a pull request:

1. Check the current branch.
2. Check git status.
3. Review the complete diff.
4. Remove unrelated changes where appropriate.
5. Run relevant tests.
6. Confirm the PR title follows Conventional Commits.
7. Complete the pull request template.
8. Create or update the pull request.

Do not automatically merge the pull request unless explicitly instructed.

When reviewing a PR, retrieve only:

- The PR.
- Relevant changed files.
- Relevant review comments.

Do not read unrelated repository content.
